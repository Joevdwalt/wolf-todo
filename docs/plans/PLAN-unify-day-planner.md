per-date selection, all-day content, task actions, overlapping items, and the
responsive inspector. Let `s` restore the last multiday range, `+`/`-` resize

timeline, including meeting and Pomodoro information. Update planner docs,
cover range, navigation, rendering and marker boundaries, run project checks,
